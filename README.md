# Portfolio

My personal portfolio for showcasing my frontend work, documenting my development process, and experimenting with new web technologies.

## About the project

This project is an opportunity to create a professional online presence while going through the complete process of planning, designing, building, testing, and deploying a website independently.

The portfolio will present my experience and capabilities through finished projects, smaller technical experiments, and the website itself. It will also provide a clear way for people to learn how I work and contact me about a potential project or collaboration.

## Goals

- Create a professional online portfolio.
- Showcase my projects and frontend capabilities.
- Practise the complete design and development process.
- Explore new web technologies and interaction patterns.
- Provide a clear way for people to contact me.

## Initial scope

- Landing page
- About me
- How we can work together
- Projects
- Contact

## Technology

- React
- React Router, using the latest stable version in Framework Mode
- TypeScript

Additional technical and design decisions will be made as the project develops.

## Project status

Planning and discovery.

The current milestone is to define the project foundation, including its documentation and sitemap, before starting application development.
