# Sitemap

> Status: Draft

This document describes the initial structure of the portfolio and the purpose of each page.

## Site structure

```text
Home /
├── About /about
├── How we work /process
├── Projects /projects
│   └── Project detail /projects/:project-slug
└── Contact /contact
```

## Home `/`
**Purpose:** introduce myself and guide visitors toward projects.
Content:
- Short introduction
- Selected projects
- Short process preview
- Contact call to action

## About `/about`
**Purpose:** give more detailed information about myself and my path on earth so far. 
Content:
- Professional background
- Experience at BMC
- Scholar background
- Skills and interests

## How we work `/process`
**Purpose:** explain how I approach a project - the 10 steps ritual. 
Content:
- Understand
- Define
- Design
- Build
- Test and launch
- Improve

## Projects `/projects`
**Purpose:** provide an overview of projects and experiments.
Content:
- Project cards
- Project type
- Short description
- Link to each case study

## Project detail `/projects/:project-slug`
**Purpose:** explain one project in depth.
Content:
- Context and objective
- Design process
- Technical decisions
- Result
- Lessons learned

## Contact `/contact`
**Purpose:** make it easy to start a conversation.
Content:
- Short invitation
- Contact details or form
- GitHub
- LinkedIn
